# 🌟 The Prospect Shop Website  

Welcome to the **The Prospect Shop** website! It is built **entirely using HTML and CSS**, without any JavaScript.  

🌍 **Live Site:** [The Prospect Shop](https://tanvirapon.github.io/Project-2/) 

## 🛠 Technologies Used  
- **HTML5** – Structuring the webpage.  
- **CSS3** – Styling and layout design.
- **Media Queries** – Ensuring responsiveness for mobile devices.  

## 📌 What I Learned  
- How to build a **complete website using only HTML and CSS**.  
- Structuring a website without JavaScript.  
- Managing a **complex design** with just HTML & CSS.
